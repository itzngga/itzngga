SEO sounds like marketing, but most of it is plain engineering. This is the checklist I run on every site.

## Help search engines find your pages

- A `sitemap.xml` that lists every page you want in search results.
- A `robots.txt` that points to the sitemap and blocks nothing important.
- Links between related pages. A page nothing links to is hard to find.

## Help them understand each page

- One clear title and meta description per page, written for people.
- One `<h1>`, then headings in order.
- A canonical link, so the same page on two addresses doesn't compete with itself.
- Structured data (JSON-LD) for things like articles, products and people.

## Make it fast and easy to use

- Small images in modern formats, with width and height set.
- Text you can read on a phone without zooming.
- HTTPS everywhere, with plain HTTP redirecting to it.

## Tell search engines you exist

- Add the site to Google Search Console and Bing Webmaster Tools, then submit the sitemap.
- IndexNow lets you tell Bing and others the moment a page changes.
- Links from your other profiles, like GitHub, help a new site get noticed.

## Then be patient

New pages can take days or weeks to show up. Check Search Console for errors, fix them, and keep publishing useful pages. Good content does most of the work.
